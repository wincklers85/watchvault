# WatchVault V2 roadmap

## Foundation (implemented)
Supabase V2 schema, Auth integration, Storage policy foundation, collection/maintenance/social/marketplace data-layer migration, password recovery, avatar upload, global search foundation and Render environment model.

## Product UI (next on this branch)
Detailed watch route and gallery, maintenance reminders, model community/reviews, social interactions, marketplace lifecycle/favorites/contact, inbox/conversations, notifications, reports/blocks and admin moderation console.

## Release gate
Export reproducible migration, clean production build, two-user RLS tests, admin authorization tests and Render feature-branch smoke test. Only then should the PR leave draft state and be considered for `main`.
